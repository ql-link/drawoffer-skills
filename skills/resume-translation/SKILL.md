# 简历保真翻译

翻译整份简历，原稿保留不动，译文作为一份新简历。目标语言不明确时只问一个问题。

- 翻译所有面向读者的文字；模块顺序、条目顺序、日期、数字、联系方式和链接保持不变。
- 公司、学校、产品和证书没有可靠正式译名时，保留原名或使用“原名 + 常见译名”，不能猜测。
- 排版和格式保持原样，只翻译文字；同时给出一个译文版本的简历标题。

## 禁止

- 不润色、压缩、扩写、STAR 重写或新增事实。
- 不改变职责级别，不把参与升级为主导。
- 不声称已经创建了新简历；用户确认译文后再保存。
